# Hello, Officer! — Where Is My Ball?

본편은 40.000초, 1920×1080, 30 fps, 1,200프레임으로 제작한다.
기존 Kokoro WAV와 대사 시작·끝, 공원과 벤치 파일을 그대로 사용한다.
윤수는 왼쪽, 경장은 오른쪽이다. 공의 중심은 벤치와 함께 세계 좌표 (1589, 654)에 고정되어 있다.

| 장면 | 구간 | 대사와 반응 |
|---|---|---|
| S01 | 0–5초 | 윤수 Y09 인사 → 경장 L02 인사 → 윤수 Y06 오른쪽 옆모습으로 듣기 |
| S02 | 5–10초 | 경장 L04 듣기 컷 → 윤수 Y01 도움 요청 → 경장 L01 대답 → 윤수 Y07이 경장을 보는 투샷 |
| S03 | 10–15초 | 윤수 Y08 질문 → 경장 L04 반응 → 윤수 Y02 찾는 시선 → 경장 반응 → Y04 옆모습 → Y03 뒷모습 투샷 |
| S04 | 15–21초 | 경장 L03 방향 소개 → 벤치 아래 공 → 윤수 Y10 기쁨의 상체 클로즈업 → 경장 반응 |
| S05 | 21–27초 | 윤수 Y05 감사 → 경장 L01 미소와 대답 → Y07 투샷으로 여운 |
| S06 | 27–33초 | 공원과 두 캐릭터 유지. Y01과 L01, 함께 말해요 안내, 원래 c03 음성 재사용 |
| S07 | 33–37초 | Y05와 L01, 현재 복습 문장 하나, 원래 c08 음성 재사용 |
| S08 | 37–40초 | Y09와 L02로 손 인사, 퇴장 이동 없이 마지막 프레임 유지 |

큰 포즈 전환은 상대 반응 컷 또는 공을 보여주는 컷 뒤에 나타난다.
PNG를 교차 페이드하지 않고 한 배역당 한 포즈만 표시한다.
단독 컷은 카메라로 화자를 보여준다. 천천히 다가가는 움직임은 2.5–3.5%다.
Y10의 발과 걸음 자세는 프레임 밖이며 이동이나 걷기 애니메이션을 추가하지 않는다.
공을 집거나 전달하는 동작은 없다.
