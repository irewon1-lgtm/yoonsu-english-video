# 윤수 별빛 사진첩

안드로이드 앱은 사진첩 화면과 재생 규칙을 받아오고 영상을 1080p로 스트리밍합니다. 내장된 초기 목록은 앱에 들어 있습니다. 영상 재생과 새 목록 확인에는 인터넷이 필요합니다.

- `web/`에는 사진첩, 에피소드별 대사 정지 지점, 브라우저 재생기와 마이크 처리 코드가 있습니다.
- `android/`는 같은 HTML을 여는 앱입니다. 안드로이드 마이크 권한과 AudioRecord PCM 입력을 사용합니다. 기본 감도 8은 알파블럭과 같은 RMS 350입니다. 기기에서 발화만 감지하며 녹음 파일을 만들거나 전송하지 않습니다.
- 말하기 차례에는 안내와 예시 문장이 끝나면 재생이 멈춥니다. 발화 종료를 감지한 뒤 1초가 지나야 재생되며, 그사이에 다시 말하면 대기를 새로 시작합니다. 마이크 연결이 끊기면 같은 차례에서 다시 연결할 수 있습니다.
- 영상은 앱에서 가로로 돌리면 시스템 막대를 숨기고 화면을 채웁니다. 영상 화면을 한 번 누르면 숨겨진 재생 버튼을 다시 볼 수 있습니다.
- 앱은 사진첩 화면을 열거나 다시 띄울 때 새 목록을 가져옵니다. 재생 중인 에피소드는 이어서 볼 수 있습니다.

## 새 에피소드 또는 화면 올리기

1. `web/episodes/<id>/`에 `index.html`과 `data.js`를 두고 `web/album.js`의 목록에 추가합니다. 정지 데이터는 `[멈출 초, 다시 재생할 초, 화면에 보일 영어 문장]`입니다. 한 장에 6개가 보입니다.
2. 작업용 미디어 폴더의 `<id>/` 아래에 H.264/AAC `film.mp4`와 `cover.jpg`를 둡니다. 영상은 모바일 탐색을 위해 `-movflags +faststart`로 내보냅니다. 변경 없는 영상과 표지는 아래 `--previous`의 목록에서 이어받을 수 있습니다.
3. 소유자 환경에서 `pip install -r requirements.txt` 후 다음을 실행합니다. 예시의 버전 번호는 현재 목록보다 큰 값으로 올립니다.

```sh
python3 scripts/pack.py --version 3 --media /private/album-media \
  --key /private/album-content.key --previous /private/current.bundle \
  --out /private/album-v3
```

4. GitHub의 `album-media` 브랜치에 출력된 `*.yvideo`를 새 버전의 폴더(예시 `album-v3/`)에 먼저 올립니다. 탐색을 위해 Raw URL의 Range 응답을 확인합니다. 마지막에 `content.bundle`을 브랜치 루트의 `latest.bundle`로 올립니다. 이전 버전의 영상 경로는 유지합니다. 버전의 영상 자산은 덮어쓰지 않습니다.
5. 소유자 기기에서 사진첩을 다시 열어 새 목록과 영상까지 확인합니다. 화면, 자막, 정지 지점과 영상 추가·교체는 APK 재설치 없이 배포할 수 있습니다.

공개 GitHub에는 이 소스와 암호화한 콘텐츠만 저장합니다. 원본 사진·영상·복호화 키·APK 서명키는 비공개 보관합니다. 다른 소유자 작업 환경에서 이어갈 때는 배포받은 개인 APK의 `assets/content.key`를 로컬 비공개 경로에 추출해 사용할 수 있습니다. 현재 목록은 `album-media` 브랜치의 `latest.bundle`입니다.

## APK 다시 빌드

안드로이드 SDK 35와 빌드 도구 35, Java, Python, zip이 필요합니다. `scripts/build-apk.sh` 상단에 명시된 환경 변수에 SDK와 소유자 키 파일 경로를 지정합니다. 같은 앱을 덮어 설치하려면 이전 배포와 같은 키스토어를 사용합니다. 영상 추가나 화면 변경만 할 때는 위 콘텐츠 배포 단계만 필요합니다.
