# 2.0 검증 범위

1. 3편의 1920×1080 영상과 자막을 확인한다. 업로드한 임의 범위 206 응답을 Android와 같은 JVM 코드로 복호화해 원본 바이트와 비교한다.
2. Galaxy Tab 비율의 세로·가로 뷰포트에서 카드 여섯 칸과 3×2/2×3 배치, 영상 화면 크기와 발화 후 재생을 확인한다.
3. 네이티브 Android 발화 검출기가 60ms 시작, RMS 350, 순수 톤 배제, 300ms 종료 규칙을 지키는지 실행한다. 브라우저에서 Android 브리지 메시지 및 수동 경로를 실행한다. 실기 설치·마이크는 물리 기기가 있을 때 확인한다.
4. 초기 번들 버전보다 새 버전을 원격에서 가져와 목록에 반영할 수 있는지 코드와 데이터 경로를 확인한다. 기존 버전은 보존한다.
5. 기존과 같은 인증서로 빌드한 설치용 APK, 공용 저장소의 코드·암호화 자산, 비공개 다운로드 파일 존재를 검증한다.
