# 윤수 방의 작은 별

1920×1080, 24fps의 플레이얼롱입니다. 제공된 방 사진의 창문, 침대, 서랍장과 구름 조명 배치를 참고해 16:9 사진 배경을 편집했습니다.

- story.json에 대사와 연습 문장이 있습니다. audio에는 화자별 개별 WAV, lips.json에는 그 음성에서 구한 발음 모양과 시간표가 있습니다.
- motion/index.json에서 각 몸동작의 원화 순서와 노출 시간을 편집합니다. sheets는 같은 원화를 순서대로 담은 개별 투명 시트입니다. 예를 들어 lamp.webp는 첫 줄 왼쪽에서 오른쪽으로 읽고 다음 줄로 넘어갑니다.
- film.py는 씻기 클럽의 Cairo 합성과 분리 렌더를 이어받았습니다. 배경은 컷마다 고정됩니다. edit.py는 시범, 윤수 차례, 같은 시범, 3초 발화 여백을 만듭니다. 대사가 없는 구간은 무음입니다.
- MP4는 발화 여백 뒤 자동 재생하는 일반 영상입니다. 사진첩 앱에서는 각 구간에서 멈추고 음성을 감지한 뒤 재개합니다.
- web 폴더에는 같은 재생기 소스가 있습니다. 해당 에피소드 폴더에 The_Little_Star.mp4를 film.mp4 이름으로 복사해 HTTPS 또는 localhost에서 열면 브라우저 마이크를 사용할 수 있습니다.
- review에 프레임·음성·동작 비교 자료가 있습니다.

Python, Cairo, FFmpeg와 DejaVu Sans, URW Bookman, Noto Sans CJK KR이 필요합니다.

```sh
python -m pip install -r requirements.txt
python edit.py
python film.py --frame 172 --out preview.png
python film.py --jobs 3
python verify.py
```

## 검수 결과
- 본편과 사진첩 스트림을 모두 디코딩했으며 3,456프레임, 2분 24초입니다. 짧은 돌발 컷은 검출되지 않았습니다. 발화 전후 경계 12개를 대조했습니다.
- 최종 MP4를 브라우저에서 1배속으로 끝까지 재생했습니다. 정해진 장면에서 507프레임을 다시 렌더한 그림과 대조했습니다. 동작 중 고정된 천장 패치의 프레임 간 최대 평균 차이는 8비트 색상값 0.516이었습니다.
- 발화 문장 12개가 독립 음성 인식에서 원문과 일치했습니다. 실제 WAV를 파형 입력 모델과 신호 검사로 검수하고, 인코딩한 40개 대사·차례 안내를 WAV와 재대조했습니다. 음질을 듣는 사람의 주관 평가는 포함하지 않습니다.

다른 작업 환경에서는 소유자 Drive의 ‘윤수 방의 작은 별 · 영상과 제작 원본’ 폴더에서 편집 ZIP을 내려받아 같은 위치에 풉니다. 프로젝트 WAV, 사적 공간 배경, 스프라이트, 재생 영상은 그 ZIP에 있습니다. 이 웹 사진첩의 재생 소스는 저장소의 web/episodes/small-star에 있습니다.
