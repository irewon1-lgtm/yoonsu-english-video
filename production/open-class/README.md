# 윤수야, 손 들어도 괜찮아! — 참관 수업 사진풍 수정본

5분 14초 · 1080p · 24fps. 영어 선생님의 질문을 듣고 윤수가 손을 들고 대답합니다. 세 단어 문장을 말하는 열두 번의 따라 말하기 구간은 각각 4초입니다.

source에는 사진풍 전신 원화가, sprites에는 실제 재생한 무손실 WebP 스프라이트시트와 프레임별 배치표가 들어 있습니다. sets는 교실 카메라이며 audio는 발화별 녹음과 타이밍입니다.
FFmpeg와 Python 3.10 이상, Noto CJK 글꼴을 설치한 뒤 python edit.py, python render.py --build-sprites, python render.py --jobs 3 순서로 재생성할 수 있습니다. 먼저 qa, delivery 폴더를 만드세요.

경장과 윤수의 보행은 기존 제작 원화를 사용했고, 윤수의 손 들기와 대화 자세는 같은 모델을 참고해 새로 제작했습니다. 엄마·친구·교사의 모습은 수업을 위한 상상화입니다. 손을 든 채 멈춘 일부 구간은 전신 자세를 유지합니다.
